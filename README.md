# Seilwindenprüfstand – Relaunch

Dieses Repository enthält die Entwicklung des WordPress-freien Relaunchs von https://seilwindenpruefstand.de/.

## Sicherheitsregeln

- Die produktive Website wird nicht automatisch verändert.
- Entwicklung und Prüfung erfolgen im Branch `relaunch-static`.
- Vor einem Upload zu Netcup sind URL-Inventar, Weiterleitungen, Kontaktformular und SEO zu prüfen.
- Keine Zugangsdaten oder Geheimnisse in dieses Repository einchecken.

## Deployment-Ziel

Statische HTML-, CSS- und JavaScript-Dateien für Netcup-Webhosting. Zunächst wird nur die Startseite umgesetzt; weitere Seiten folgen nach Prüfung des URL-Inventars.
